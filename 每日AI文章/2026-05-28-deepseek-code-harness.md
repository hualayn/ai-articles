# DeepSeek 的终极野心不是模型，是编程工具

中国 AI 圈有一个正在悄悄发生变化的事：竞争焦点已经从"谁的模型跑分更高"，转向"谁能把模型变成真正好用的产品"。

DeepSeek 最近的几个动作，恰好踩在了这个转变的节点上。

---

## 一个被断供的市场

先说背景。Claude Code 是目前 AI 编程领域的标杆工具——它能持续自主编码长达 5 个小时，从写代码、编译、启动应用到自动测试，一个指令跑完全流程。最近还推出了 Routines 功能，把"代码生成""重构""评审"这些固定动作模块化、自动化。

但它对中国不可用。中美 AI 竞争白热化，Claude Code 的缺席给中国开发者留下了一个巨大的空白。

市场却在疯长。中国 AI 编程工具市场 2025 年规模已达 24.5 亿元，一年翻了近两番（增速 187.3%），活跃用户 280 万。预测到 2030 年会膨胀到 253.8 亿元，年复合增长率 40%。全球范围内，84% 的开发者已经在工作中使用 AI 工具。

DeepSeek 看到的不是一个市场缺口，而是一扇可以直接走进开发者日常的门。

---

## Model + Harness = Agent

DeepSeek 提出的新公式很简洁：Model + Harness = Agent。

Harness 的中文意思是"缰绳"。形象地说，大模型像一匹千里马，Harness 就是那根缰绳——负责牵住它往你希望的方向狂奔。

在这个公式里，模型只是"大脑"，Harness 才是连接大脑和双手的"神经"。它负责把模型的能力带入真实的工程环境：读项目结构、管理上下文、控制 Token 消耗、执行 Git 操作、处理终端命令、跑 CI/CD、管理权限和审计记录。

这比"对标 Claude Code"这种泛泛口号具体得多。

团队成立后，招的不是只会搞模型的研究员，而是产品经理和研发工程师。要求很明确：深入参与桌面端 Agent 产品研发，把真实任务反馈带回模型训练。

这意味着 DeepSeek 不只想提供 API，而是要自己做一款能用的、好用的生产力产品。

---

## 成本优势，几乎是碾压级的

DeepSeek 手里最狠的一张牌，是成本。

DeepSeek V4 系列模型推理成本削减了 98%，综合成本只有海外同级模型的约 1%。另一种算法是推理成本低至 GPT-5.5 Pro 的千分之 1.55。

便宜的底气来自底层架构重构。新的注意力机制把 KV 缓存缩减到原来的十分之一。这意味着 DeepSeek Code Harness 将来可能极便宜，甚至部分免费。对成本敏感的国内开发者来说，这个吸引力几乎是无解的。

另一层优势没那么直观，但同样关键——全栈自研。

模型是自己的，Harness 框架也是从头造。很多开发者吐槽过"模型很强但工具链各种别扭"，在全栈自研的体系里，这类问题从根源上就不存在。

---

## 社区先等不及了

有意思的是，官方产品还没影，社区先等不及了。

一个叫 DeepSeek-TUI 的开源项目，今年 5 月直接冲上 GitHub 热榜第一，Star 数几天内突破 1.2 万。作者是美国独立开发者 Hunter Bown，用 Rust 写的，目标很纯粹——给 DeepSeek 模型一个能和 Claude Code 掰手腕的原生 Agent 框架。

它基于 V4 模型的百万级上下文窗口，还能实时显示成本消耗。

这件事说明，把 DeepSeek 模型能力产品化的需求，已经是嗷嗷待哺了。官方什么时候出正式产品，市场已经等不及。

---

## 更深的布局

团队搭建的方向，也值得注意。

崔添翼的加入受到广泛关注。他本科浙大计算机系，6 次获得 ACM 亚洲区域赛金牌，之后在 Jane Street 量化交易公司工作 9 年并联合创立了 TSY Capital。

为什么招量化交易背景的人做 Code Agent？因为 Code Agent 的难点不只是生成代码，还要在真实项目里持续执行任务。量化交易系统长期强调低延迟、稳定性、自动化执行和风险控制——这些经验放到 Agent 工程系统上，范式是相通的。

资深研究员陈德里也直接发招聘，提到要从零构建 Code Harness。他的表述很明确：在 Agent 产品中，模型负责理解和生成，Harness 负责把能力带入真实环境。

---

## 编程工具，不只是工具

Google CEO Sundar Pichai 最近在 Hard Fork 采访里公开承认：Google 在文本、多模态、语音、推理上都很有竞争力，但在 agentic coding 上——工具调用、指令跟随、长周期任务——还有差距。

他还提到更关键的一点：coding 是一个需要接触 data flows 的领域。终端工具能看到开发者如何提出任务、如何追问、什么时候接受建议、什么时候放弃。它还能通过测试结果、终端日志、文件变更和 Git 提交，判断一次 Agent 执行是否完成任务。

这类数据对 coding 模型和 Agent 产品来说，价值极高。

DeepSeek 的逻辑链就是这样：低价 Token 吸引开发者，低缓存价格让 Agent 任务跑得起，Code Harness 让模型进入开发环境，真实工作流数据反哺模型迭代。

降价只是推下山的第一把力，后面靠数据飞轮越滚越大。

DeepSeek 做编程工具不是一时兴起。目标、人才、技术、市场需求，全都到位了。这件事传递的信号也很清楚：国内 AI 竞争的下半场，拼的不是 Benchmark 分数，而是谁能把模型变成开发者每天离不开的工具。

DeepSeek Code Harness 什么时候见面，是目前唯一剩下的问题。
