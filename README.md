# AI Articles

这是一个用于跟踪、分析和撰写 AI / 科技领域热点文章的 Obsidian 仓库。

## 用途

- 记录和整理 AI 领域的重大事件与动态
- 撰写结构化分析文章（市场、技术、政策、产业链视角）
- 作为长期知识库，与 Obsidian 双向链接配合使用

## 目录结构

- `每日AI文章/`：日常 AI 热点新闻与事件分析
- 其他文件夹可按主题/项目逐步扩展

## 规范

- 文章使用 Markdown 格式
- 文件命名建议：`YYYY-MM-DD-主题关键词.md`
- 优先保证：事实准确、逻辑清晰、语言克制

## 说明

- 本仓库通过 Git 进行版本管理
- 使用 Obsidian 作为编辑器，支持双向链接与笔记管理
